Текущие шаги фабрики, активные модули и параметры, отложенные альтернативы и

Для автономного реального графа без S2 см. [unarXive и совместимость исходного API](UNARXIVE.md).

Согласованный шаг 1 фабрики реализован отдельно от технического bootstrap:

Реализован [конвейер шага 1.5](FACTORY_STEP1_5.md): план, оценка пар, остановка
по правилу 3 из 5 и пересчёт порога без новых LLM-запросов. Научный

с промптом v2 дал 13 принятых затравок из тех же 20, 75 запросов без ошибок.
Рост допуска не заменяет содержательную проверку качества;
лимиты старого smoke-конфига не подставляются автоматически.

Запускать из корня репозитория с `PYTHONPATH=code`. Модуль не импортирует и не возобновляет сборщики лексического эксперимента. Старый кеш подключается только явным `--legacy-root` и читается без изменения файлов. Исходники pasa2 также читаются без изменения. Новые данные сохраняются в собственной папке запуска.

Зависимости: Python 3.11+, системный `curl` с рабочим хранилищем TLS-сертификатов, пакеты из соседнего `requirements.txt`. Для тестов дополнительно нужны `pytest` и `httpx`. При передаче `--merger` используется функция `process_row` из указанного **доверенного Python-файла**; на этой машине это существующий `pasa2/compile_arxiv.py`.

## Подготовка локального каталога

```sh
PYTHONPATH=code python3 -m graph_pilot --db research/local-graph-pilot/pilot.sqlite index \
  --parquet /Users/n.gulyakov/Desktop/work/pasa2/arxiv_part_0045.parquet \
  --merger /Users/n.gulyakov/Desktop/work/pasa2/compile_arxiv.py \
  --legacy-root research/terminology-pilot \
  --snapshot-id local-june2026-s2-pilot-2026-10-18

PYTHONPATH=code python3 -m graph_pilot --db research/local-graph-pilot/pilot.sqlite seeds --count 3
```

Индексируются только небольшие колонки метаданных Parquet. Для LaTeX сохраняется locator `(row_group, row_index)`: наличие строки означает **зарегистрированный источник**, а не проверенную доступность текста. Проверка и объединение выполняются при чтении конкретной статьи. Объединённый результат кешируется отдельно в gzip. Статус `available` означает успешное извлечение, а не экспертную проверку содержимого. Статусы `partial`/`no_main` merger’а не считаются успешным текстом.

Старый кеш содержит разные представления: извлечённый текст и body без библиографии. Формат, качество и происхождение возвращаются явно. Их нельзя молча считать сырым LaTeX или полным PDF с библиографией. Статьи S2, для которых позже появился arXiv ID, объединяются с сохранением локального источника.

Три стартовые статьи выбираются воспроизводимо из `cs.CL`/`cs.IR`, сортировка по SHA-256 с фиксированным префиксом. Проверяются тексты не более 30 кандидатов. Это **технический bootstrap**, а не согласованный шаг 1 научной фабрики: исследовательские параметры m, D_max и бонус площадки здесь не подменяются.

## Проверка сети и ограниченный сбор

```sh
PYTHONPATH=code python3 -m graph_pilot --db research/local-graph-pilot/pilot.sqlite probe \
  --seconds 180 --max-requests 12 --retries 2

PYTHONPATH=code python3 -m graph_pilot --db research/local-graph-pilot/pilot.sqlite collect \
  --seconds 3600 --max-expanded 300 --max-nodes 10000 --max-depth 2 \
  --max-requests 2500 --pages-per-direction 3 --retries 2
```

Если в окружении задан `S2_API_KEY`, он передаётся через stdin системного curl. Ключ не записывается в аргументы процесса, JSON-кеш или журналы. Без ключа используется публичный пул; его доступность не гарантирована. В этой сессии Python requests не доверял локальной цепочке сертификатов, поэтому транспорт использует системный curl; проверка сертификатов остаётся включённой.

Один клиент выполняет запросы последовательно с интервалом минимум 1,1 с. При 429, временных серверных и транспортных ошибках — максимум два повтора с ожиданием 15/30 с. После исчерпания повторов сбор останавливается, а не обходит остальные 300 статей с тем же сбоем. HTTP 404 означает отсутствие записи в S2, а не отсутствие статьи или её цитирований.

Рёбра `(src,dst)` означают «src цитирует dst». `references` раскрывает исходящие связи, `citations` — входящие. Дубли и самоссылки не увеличивают степени. Граф ограничен статьями с arXiv ID; неразрешённые и внешние соседи учитываются отдельно. Обнаруженные вершины отличаются от раскрытых: ограничение 300 относится к различным статьям, для которых начато раскрытие. Отдельно сохраняется число полностью раскрытых статей.

Ограничение глубины: раскрываются глубины 0 и 1; вершины глубины 2 остаются на границе. Обе стороны раскрываются независимо. Максимум три страницы по 1000 соседей на направление в одной попытке раскрытия; при достижении лимита сохраняется `page_budget`, а не `complete`.

Сохранение одной страницы и следующего offset выполняется атомарно. Успешные HTTP-ответы кешируются; ошибки не используются как успешный кеш. Повтор той же команды продолжает незавершённые направления, не дублируя рёбра. При изменении конфигурации история сохраняется в `events`; для независимого эксперимента нужен новый каталог/БД. Ctrl-C и бюджеты оставляют checkpoint; при жёстком завершении процесса незавершённая транзакция откатывается.

`snapshot_id` обозначает локальную коллекцию наблюдений API. Это не глобальный release S2: у ответов есть время получения, API может меняться между запросами. `total_local` — число сохранённых уникальных соседей, удалённые citation/reference counts сохраняются отдельно. Отсутствие локальных рёбер не означает полный пустой список. Полнота направления есть только при `remote_list_complete=true`.

Пилот не скачивает новые полные тексты, не запускает модели и не создаёт оценочные задачи. Это шаги 1–3 локального плана; получение текстов новых соседей относится к следующему шагу.

## API и чтение без сервера

```sh
PYTHONPATH=code python3 -m graph_pilot --db research/local-graph-pilot/pilot.sqlite serve --port 8765
PYTHONPATH=code python3 -m graph_pilot --db research/local-graph-pilot/pilot.sqlite text arxiv:2606.09887
PYTHONPATH=code python3 -m graph_pilot --db research/local-graph-pilot/pilot.sqlite report
```

Сервер слушает только `127.0.0.1`, один worker. Документация — `/docs`.

- `GET /healthz` — размеры каталога/графа, полнота и причина остановки.
- `GET /paper?paper_id=...` — метаданные, доступность и качество локальных источников.
- `GET /text?paper_id=...` — текст с форматом и происхождением; 404, если локального читаемого текста нет.
- `GET /neighbors?paper_id=...&direction=references&limit=50&offset=0` — соседи и статус полноты; `citations` возвращает входящие.

ID передаются query-параметром, поэтому старые ID со слешем поддерживаются. Можно передавать arXiv ID с версией, `arxiv:...`, URL arXiv или `s2:<paperId>`, если соответствие уже известно.

Для чтения из Python: `Store(path).paper(id)`, `.neighbors(id, direction)`, `Texts(store).get(id)`. Соединение следует закрывать через `.close()`.

Артефакты: `pilot.sqlite`, `text-cache/`, `s2-cache/requests.jsonl`, кеш успешных ответов и `summary.json`. В БД также хранятся явный manifest локальных источников, конфигурация и события. Данные и кеш игнорируются Git, исходники и итоговый краткий отчёт можно версионировать.

