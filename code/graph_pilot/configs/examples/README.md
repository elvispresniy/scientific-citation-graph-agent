# Профили LLM

Эти профили сохраняют настройки экспериментов, но используют адрес
локального совместимого сервера. Перед новым запуском скопируйте нужный
файл на один уровень выше и задайте base_url своего провайдера и model.

- step2-llm.example.json — карточки, расширение, вопросы и судья.
- step1_5-llm-run.json — предварительная проверка затравок.
- step1_5-llm.example.json — небольшой проверочный запуск.
- llm-server.json — минимальный профиль соединения.

Рабочие файлы конфигураций исключены из Git. Изменение конфигурации
требует подготовки нового запуска. Ключ передаётся отдельно через
GRAPH_LLM_API_KEY или локальный файл .secrets/llm-api-key.

Точное соответствие серверного alias опубликованному checkpoint модели
пока не установлено. В статье указан использованный alias qwen38_27b.
