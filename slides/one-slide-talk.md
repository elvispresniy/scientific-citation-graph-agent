# Однослайдовый доклад на одну минуту

[Слайд](one-slide.pdf) · [Исходник](one-slide.tex)

> Статьи об одной научной проблеме могут использовать разные термины. Из-за этого часть подходящих работ может остаться за пределами прямой выдачи. По ссылке можно перейти к статье независимо от её позиции в выдаче.
>
> Я строю фабрику поисковых задач. Мы начинаем с одной статьи и расширяем её окрестность по ссылкам и цитированиям. Внутри подграфа выделяем группу работ с общим научным аспектом. По этой группе модель формулирует запрос и предлагает статьи, которые могут на него ответить.
>
> Затем модель отдельно проверяет каждую статью по полному тексту. Для кандидатных целей смотрим, где они оказываются в прямой выдаче.
>
> На таких задачах можно проверить, когда обход цитирований помогает найти статьи, которые прямой поиск пропустил.

## Если спросят

- **Что показано на рисунке?** Схематичный подграф. Зелёным выделены статьи с общим аспектом, из которого формулируется запрос.
- **Что уже сделано?** На локальном срезе графа получены пилотные запросы, вердикты полнотекстовой проверки и позиции кандидатных целей в прямой выдаче.
