# Массовое сравнение словаря вопросов и целевых статей

Алгоритм применён ко всем **2101 вопросам и 65,458 парам** из тех же зафиксированных релизов. Основная таблица ниже исключает 30 вопросов настройки: остаются **2071 вопросов / 64,865 пар**. Новые вопросы не отбирались по удобству или результату. У 60 исходных строк AutoResearchBench нет ID ответа, поэтому они не образуют пары. Crase не подменяется другим набором. PaperPilot — доступный 50-строчный CSV, соответствие каноническому тесту не подтверждено.

**Охват текущего снимка:** значения по заголовкам и аннотациям получены для 64,580 из 64,865 пар оставшихся вопросов. Сбор остановлен по просьбе пользователя ограничить длительность эксперимента. Срез зафиксирован в `frozen-slice.json`; автоматического возобновления нет. Ниже приведены результаты по фактически доступным данным, а не вымышленные значения для всего релиза. Текущее состояние фонового процесса записывается в `driver-progress.json`, состояние текстов — в `collection-progress.json`.

## Зафиксированный алгоритм

1. Выделить именные группы с определениями фиксированным POS-теггером NLTK, используя только запрос. Удалить служебные слова и фиксированную оболочку поиска.
2. Взять разные исходные слова этих групп; нормализовать существительные только при единственном словарном анализе WordNet.
3. Посчитать долю слов, найденных в статье. **Лексическое расхождение = 100% − найденная доля.**
4. Отдельно сохранить точное покрытие без нормализации, совпадение групп целиком и контроль по всем содержательным словам.

Этот алгоритм не использует генеративную модель, платные токены или подстройку терминов под целевую статью. Отбор именных групп согласован с пилотным словарём лучше двух проверенных альтернатив, но пилотный словарь не является независимой экспертной разметкой. Совпадение измеряет написанный словарь, а не смысловую эквивалентность и не успешность поиска. Отрицательные темы сохраняются как упомянутая лексика; проверка отрицательных требований здесь не проводится. **Известное ограничение автоматического отбора:** слово `using` может попасть в термин, а отдельные выражения — склеиться в одну группу. В этом срезе правило сохранено; показатели предварительные, объективность оценки терминологического разрыва не установлена.

## Что получилось сравнить по полному тексту

Надёжно очищенный полный текст сейчас имеется для 12759 пар оставшихся вопросов. Состояние сбора: `frozen_time_limited`. Использованы уже собранные статьи пилота и успешно полученные новые тексты. Это **доступное подмножество, а не полная полнотекстовая выборка релизов**. Тексты остальных целей ещё не загружены или недоступны; их показатели записаны как пропуски. На подмножестве, определяемом доступностью источников, нельзя делать вывод о полном бенчмарке.

| Одинаковые доступные пары | Пар | Совпадение слов | Расхождение слов | Группы целиком |

| Без библиографии | 12759 | 75.3% | 24.7% | 31.4% |
| Без библиографии и явно выделенного Related Work | 12759 | 73.9% | 26.1% | 30.4% |

## Проверки и файлы

Проверены: все ID пар, отсутствие дубликатов, границы автоматически выделенных выражений в исходном вопросе, диапазоны значений, фиксированные знаменатели и вложенность доступных текстовых представлений. Во всех строках сохраняются исходные найденные и отсутствующие слова; пропуск сопровождается причиной.

- `questions.jsonl` — оригинальные вопросы и полный список опубликованных целей.
- `query-terms.jsonl` — автоматические выражения и их точные границы.
- `pair-metrics.jsonl` — все пары, три представления, показатели и найденные/отсутствующие слова.
- `question-metrics.jsonl` — сводка по каждому вопросу.
- [Все исходные вопросы, автоматически выделенные выражения и показатели](question-results.md).
- `summary.json`, `inventory.json` — охват, источники, хеши и ограничения.
- `excluded-questions.jsonl` — исходные вопросы без целевого ID, сохранённые с причиной.
- `papers.jsonl` и `cache/` — локальные метаданные и ответы источников; крупные входные данные исключены из Git.
