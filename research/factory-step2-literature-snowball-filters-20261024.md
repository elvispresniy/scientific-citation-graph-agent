## Что действительно описано в работах

**Crase — Problem formulation; Guided graph expansion; Source ranking; приложения H, K.** Вначале собираются все соседи seeds и связи внутри этого множества; индивидуального допуска по релевантности запросу перед расширением нет. Далее оценивается поддержка утверждений вдоль цитирований: удаляются рёбра с нулевой поддержкой и изолированные узлы, остальные ранжируются PPR/SALSA. Узел вне итогового top-k может участвовать в распространении веса. Извлекаются 4–5 основных утверждений из заголовка, аннотации и введения. Рекурсивного расширения нет. Авторы прямо признают невозможность восстановления при seeds вне нужной области.

**Wohlin — §§3.1–3.4, PDF с.2–4; §§4.6, 4.9.1, с.7–9.** Перед snowballing статья должна быть окончательно включена; иначе при последующем исключении требуется rollback. Нерелевантный навигационный узел отдельно не предусмотрен. Для первичного отбора используется контекст цитирования; неизвестный автор не основание отказа. Предупреждения: строгий отсев по заголовкам теряет подходящие работы; повторы могут означать замыкание в одном авторском кластере; независимые кластеры требуют разнообразного стартового набора. Рекомендуются обе стороны цитирования, матрица связей и дополнительные способы поиска. Полнота всех связующих работ не гарантируется.

## Интерпретация для нашей фабрики — предложения субагента

Следующие положения не являются буквальным алгоритмом этих статей и не согласованы с пользователем.

1. Разделить два решения: «оставить в будущих целях» и «разрешить использовать для продолжения обхода». Простое исключение статьи из целей не должно автоматически означать удаление всех доступных через неё продолжений.
2. Различать **библиографический мост** (соединяет области путями цитирования) и **содержательный мост** (даёт проверяемое основание сопоставить научные результаты). Первый не доказывает второй. Роль моста лучше сохранять отдельно от пригодности статьи в итоговую группу.
3. Допуск для навигации может оставаться предварительным: неизвестная полезность продолжения не равна доказанной бесполезности. В ограниченном бюджете это требует отдельной политики исследования, а не обещания сохранить любой мост.
4. Для проверки такой политики понадобятся случаи, где путь к подходящей статье проходит через непригодную в цели работу. Одна доля положительных попарных сравнений этого свойства не измеряет.

В нашей постановке ещё нет конечного запроса: перенос query-relevance напрямую некорректен. Вышеописанное разделение ролей предлагается относительно накапливаемого набора и предварительных научных связей. Топологический статус подтверждается лишь на уже известном подграфе; полезность непросмотренных продолжений заранее не установлена.

Ни одна из двух прочитанных работ не даёт универсального решения сохранения промежуточных статей: Crase ограничивает пространство, Wohlin допускает расширение только после включения. Механизмы Swanson по недоступному полному тексту здесь не реконструируются.
