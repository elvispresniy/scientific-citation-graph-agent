# Число компонент LSA и ошибка поиска

Корпус — 10000 сохранённых текстов index-001. Вопросы — 33 исходные
формулировки из questions-status-20261115 с 86 положительными парами.
Переформулированные запросы не используются.

```sh
PYTHONPATH=code python3 -m graph_pilot.lsa_complexity --output research/lsa-complexity-20261119/run-002
python3 code/plot_lsa_complexity.py --results research/lsa-complexity-20261119/run-002/results.json
```

Каталог нового расчёта должен отсутствовать. run-001 содержит выполненный
эксперимент. Его config.json фиксирует хеши входов, версии библиотек,
идентификаторы вопросов и настройки. results.json сохраняет ранги всех
кандидатных целей и метрики по вопросам.

TF-IDF и его словарь фиксированы. Размерности LSA — 32,64,128,256.
random_state=42, выдача top-20, косинусное сходство. Для 128 компонент
используются замороженные transform.joblib и vectors.npy, их SHA-256
проверены до и после расчёта. Сохранённые ранги всех целей воспроизведены
точно. Для остальных размерностей выполнен один новый fit TruncatedSVD.

| Компоненты | Найдено пар | Средний пропуск | Выборочное SD |
|---|---|---|---|
| 32 | 36/86 | 56.9% | 45.2 п.п. |
| 64 | 47/86 | 41.9% | 44.4 п.п. |
| 128 | 51/86 | 33.9% | 42.7 п.п. |
| 256 | 58/86 | 26.1% | 38.6 п.п. |

Среднее и SD рассчитаны по 33 вопросам с равными весами. Они отличаются
от доли пропущенных пар в объединённом пуле. Полоса графика показывает
межвопросный разброс. Разброс повторных SVD-fit здесь не измерялся.

Это разработочная выборка с модельной разметкой ограниченных пулов.
Размерность 128 участвовала в исходном построении индекса и задач.
Результат характеризует чувствительность покрытия известных целей.
Оптимальная размерность и качество на независимой выборке не установлены.
